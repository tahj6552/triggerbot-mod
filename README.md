# Triggerbot (Fabric 1.21.11)

Client-side mod. Attacks any player in your crosshair once your attack cooldown is full.
Press **Page Down** to open the GUI and toggle it ON/OFF (rebindable in Controls).

Build: push to GitHub, open the Actions tab, and download the `Artifacts` zip from the run.
The mod jar is the one in it WITHOUT `-sources` in the name. Needs Fabric Loader + Fabric API.
